# 대시보드 따라하기

설치·가중치 받기가 끝난 상태에서 시작한다 (`README.md` 의 "5분 시작"). 화면은 왼쪽에 상태 카드,
오른쪽에 탭 7개다: **준비 → 프롬프트 → 미리보기 → 학습 → 임계값 → 검사 → 내보내기**.
숫자는 MVTec LOCO `breakfast_box`(양품 351 · 검증 62 · 불량 20)로 실제 돌린 값이다.

```bash
anofit serve            # http://127.0.0.1:8732 — 원격 GPU 기계라면 SSH 터널로 연다
```

맨 위 띠에 버전과 GPU 이름, 라이선스/체험 상태가 보이면 정상이다.

---

## 1. 준비 — 이미지 넣기

세 종류를 각각 넣는다. 종류 드롭다운을 먼저 고른다.

| 종류 | 예시 장수 | 쓰임 |
|---|---:|---|
| **양품** — 학습에 쓴다 | 351 | 최소 16장, 권장 50장 이상 |
| **검증 양품** — 임계값 산정에만 | 62 | 따로 넣으면 양품은 전부 학습에 쓰인다 |
| **불량** — 학습에 안 쓴다 | 20 | 체크포인트 선택과 임계값 확인. **정확도를 좌우한다** (§4-4) |

넣는 길은 둘이다:

- **브라우저 업로드** — 사진이 PC 에만 있을 때. 12 MB 씩 나눠 보내므로 수백 장도 된다.
- **서버 폴더에서 가져오기** — 사진이 대시보드가 도는 기계에 있을 때. 경로를 넣고 **가져오기**.
  브라우저를 거치지 않고 제자리에 연결한다(351장 1초). 기본은 바꿔치기 — 이전 품종이 섞이지 않는다.

> **검증 양품은 학습분과 다른 때 찍은 것으로.** 같은 촬영분으로 교정하면 예상 오검출이 낙관적이다 —
> 실측으로 6% 라던 것이 다른 날 찍은 양품에서는 30% 였다.

왼쪽 **올린 이미지** 카드에 장수와 `← 출처`(폴더 이름 끝 세 조각)가 뜬다. `⚠ 두 출처` 는 다른
품종이 섞였다는 뜻이다 — 학습 전에 반드시 확인한다.

## 2. 프롬프트 — 부품 태그 뽑기 (논리부에만)

양품에 RAM++ 를 돌려 태그 후보를 모으고 GroundingDINO 로 실제 박스를 재서 가려낸다.
표본 24(기본)로 **후보 뽑기** → 몇 분 뒤 제안 프롬프트가 채워진다.

**비워 두어도 된다.** 비우면 학습이 자동 추출한다. 검증된 5품종 정확도는 전부 자동 추출 프롬프트로
얻었다. `breakfast_box` 의 자동 프롬프트는 이랬다:

```
cereal . container . granola . nut . oatmeal . oats . orange . tray . almond . seed . apple . raisin . peach . banana .
```

## 3. 미리보기 — 분할을 눈으로

학습은 수십 분이 걸린다. 그 전에 12장만 그려 본다. **품종 ID** 를 넣으면 프로파일이 값을 채운다
(검증된 이름이면 `검증됨` 배지). 프롬프트를 넣고 **그려 보기**.

| 열 | 보는 것 |
|---|---|
| orig | 원본 |
| sam | 검출·분할이 색으로 덮인 것 — 부품이 잡혔는가 |
| cluster | 최종 부품 클래스 — 같은 종류가 같은 색인가 |

진행 카드에 `num_classes 8` 같은 칩이 뜬다. 클래스 수가 기준과 같다고 정확도가 오르지는 않는다
(pushpins 에서 군집을 기준과 똑같이 맞췄더니 62.73 → 55.64). 이 화면의 목적은 분할이 **무엇을 하고
있는지 보는 것**이다. `max_hyper` 는 방향이 단조롭지 않다(2.0→2개, 3.5→3개, 6.0→2개) — 여러 값은
CLI `anofit preview --sweep 2,3,3.5,5,8`.

## 4. 학습

### 4-1. 품종 ID

이름을 넣으면 프로파일이 폼을 채운다. 검증된 이름(`breakfast_box`·`juice_bottle`·`pushpins`·
`screw_bag`·`splicing_connectors`)이면 확정 인자가, 그 밖이면 기본값이 들어간다.
**폼에 보이는 값이 곧 보내는 값**이다 — 고치면 그 값이 프로파일을 이긴다.

### 4-2. 모드

| 모드 | 시간 (RTX 4090, 양품 351) | 배우는 것 |
|---|---|---|
| struct | 약 40분 | 표면 흠집·파손 |
| logic | 약 25분 (정밀 분할이면 75~95분) | 부품 개수·구성 |
| both | 약 65분 | 둘 다 — 기본이자 실제 검사용 |

### 4-3. 시드

기본 42. 재현용이지 정확도용이 아니다. 같은 시드라도 세그멘터의 최종 에폭 성적은 ±7 흔들린다
(같은 설정 두 번: 91.08 / 83.75). 그래서 다음이 중요하다.

### 4-4. 불량 이미지 — 정확도를 좌우한다

| 불량 | 체크포인트 선택 | breakfast_box 실측 |
|---|---|---:|
| 8장 이상 | 불량 AUROC 가 가장 높은 에폭 | 93.74 |
| 0~7장 | 마지막 에폭 (고르지 않음) | 96.17 |
| (예전 방식) | 양품 점수만으로 고름 | 83.75 |

양품만으로 고르는 방식은 무작위보다 나빴다 (5품종 평균: 양품 기준 72.24 · 무작위 76.24 ·
마지막 에폭 78.45 · 불량 기준 83.98). 불량이 없으면 마지막 에폭을 쓴다.

### 4-5. 배경 처리

| 선택 | 뜻 |
|---|---|
| 빼지 않는다 (기본) | 검증된 5품종 전부 이 조건의 값이다 |
| 이름은 모르지만 빼 줘 | 기하 판정 — 프레임 대부분을 덮고 다른 검출을 여럿 품거나 경계에 닿는 박스 |
| 이 이름으로 | 그 단어가 든 검출을 배경으로 |

트레이·봉투가 부품으로 섞여 개수 판정이 흐려질 때만 나머지를 고른다.

### 4-6. 정밀 분할 (no_sam)

| 값 | 시간 | 언제 |
|---|---|---|
| true | 품종당 5~10분 | 박스만. breakfast_box · pushpins · splicing 의 확정값 |
| false | 25~95분 | SAM-HQ 정밀. juice_bottle · screw_bag 의 확정값. 24 GB 미만 GPU 는 사실상 불가 |
| both | 합한 시간 | 두 번 학습해 불량으로 비교 — 불량 8장 이상일 때만 의미 |

"항상 정밀이 낫다"는 성립하지 않았다. 품종마다 이기는 쪽이 다르다.

### 4-7. 시작하고 지켜보기

**학습 시작** → 왼쪽 진행 카드: `BEGIN → split → struct → logic → select → assemble → DONE`,
경과와 남은 시간. **▶ 학습이 알려 준 것** 을 꼭 펼친다 — 로그 꼬리와 달리 중요한 줄만 모인다:

| 표지 | 뜻 |
|---|---|
| `PROFILE:` | 어떤 프로파일이 적용됐고 사용자가 무엇을 명시했는지 |
| `PROFILE-WARN:` | 설정만으로 알 수 있는 문제 |
| `[PL-SUM]` | 의사라벨 결론 — 컴포넌트·군집·클래스 수 |
| `[BG]` `[BG-WARN]` | 배경 처리 실적과 경고 |
| `[CACHE]` | 의사라벨을 다시 만들었는지 재사용했는지 |
| `select:` | 어느 에폭을 무엇을 근거로 골랐는지 |

```
select: 불량 20장 ≥ 8 → 불량 기준; epoch 35 선택 (defect_auroc=0.9516)
```

이 한 줄이 논리부를 83.75 에서 93.74 로 올렸다.

### 4-8. 불량을 나중에 얻었다면 — 재학습하지 않는다

준비 탭에 불량을 넣고 같은 설정으로 **학습 시작**. 학습을 건너뛰고 `rescore` 만 돈다 — 스냅샷을
지금 불량으로 다시 채점해 체크포인트를 다시 고른다. 약 12분.

## 5. 임계값 — 양품 몇 장이 걸리나

학습이 끝나면 번들이 열린다. 모드를 고르고 σ 슬라이더를 움직인다: 임계값 · 걸리는 양품 · 비율 ·
오검출 0 이 되는 σ. 막대는 검증 양품의 점수 분포, 세로선이 임계값이다.

이 숫자는 교정에 쓴 양품 기준이라 낙관적이다. 따로 찍은 양품으로 재려면:

```bash
anofit threshold <번들> --holdout <다른 날 찍은 양품 폴더>
```

모드 이름은 파이프라인 이름이지 결함 종류가 아니다. 이름으로 고르지 말고 표를 본다.

## 6. 검사 — 한 장

모드를 고르고 이미지를 넣는다: 융합 점수와 OK/NG, 분기별 막대(무엇이 반응했나), 이상맵 오버레이(어디를 봤나).

## 7. 내보내기

가중치·메타·임계값·검증 원점수를 `.afz` 하나로. 학습 캐시는 안 들어간다 — 이 파일만 옮긴다.
받는 쪽은 `anofit import <파일>`.

## 자주 막히는 곳

| 증상 | 대처 |
|---|---|
| "이미 도는 작업이 있다" | GPU 하나에 잡 하나. 끝나거나 **중단** 뒤에 |
| `doctor` 가 "파운데이션 파일 없음" | `anofit fetch --mode <모드>` — 폴더만 있고 비어 있어도 잡아낸다 |
| 학습 시작이 "체험 기간이 끝났습니다" | `anofit license --install "<key>"`. 이미 학습한 번들로 검사는 계속 된다 |
| 폴더 가져오기가 "복사" 로 떨어짐 | 링크가 안 되는 파일시스템. 정상이며 느릴 뿐 |
| 정밀 분할이 몇 시간째 | 24 GB 미만 GPU. `no_sam=true` 로 |
